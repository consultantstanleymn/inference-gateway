# Architecture decision records

This folder holds the architecture decision records (ADRs) for the engagement.

## Earlier decisions

The existing decision list is in [`docs/DECISIONS.md`](../../DECISIONS.md). It has items 1 to 12. Those items are the earlier decisions. Read them first.

## ADRs in this folder

New ADRs here start at number 0003, because the items in `DECISIONS.md` are the earlier ones.

| ADR | Title | Status |
|---|---|---|
| [0003](0003-gpu-and-fine-tuning.md) | GPU serving and fine-tuning | accepted |

## Format

Each ADR has these parts: context, options, criteria, decision, reopen trigger, consequences and status. Keep each ADR at decision level. State clearly what was built, run or measured, and what was not.
